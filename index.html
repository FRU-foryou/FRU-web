FAQ

常見問題與解答

Q1：我完全不懂寫程式或架伺服器，後續會很難維護嗎？

完全不會！所有後台排程、休假日與服務項目調整，只要像平常打開手機 Google 試算表打字一樣簡單，修改後前台預約系統會在 3 秒內自動同步，零學習門檻。

Q2：從諮詢、規劃到系統實際上線，通常需要多久？

需求確認並盤點好您的排程規則與視覺風格後，標準方案約 7~14 個工作天內即可完成壓力測試並正式上線交付。

Q3：後續每個月需要支付伺服器或平台維護費嗎？

不需要！我們採用 GitHub 與 Google Apps Script 無伺服器（Serverless）架構，在正常的商業用量下主機費與資料庫皆為 0 元，沒有任何隱藏月費。

Q4：目前已經有在使用其他預約系統，能無痛轉移嗎？

可以的！我們會協助您將現有的舊客名單、服務價目表與慣用排班規則完整轉移，並設定 LINE@ 導流連結，讓老客人能無縫體驗全新系統。
